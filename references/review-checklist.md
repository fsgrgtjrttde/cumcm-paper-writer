# CUMCM 论文终检清单

## 官方规则

- [ ] 目标届次和官方页面已在本轮打开核验。
- [ ] 纸质版与电子版的承诺书、编号页、摘要页边界正确。
- [ ] 摘要原则上不超过一页；正文不超过 30 页；正文没有目录。
- [ ] 电子论文和支撑材料分别不超过 20 MB。
- [ ] 匿名区没有姓名、学校、赛区、队号、水印或文件名泄露。

## 证据与内容

- [ ] 每个子问题都有主张-公式/代码-图表-验证闭环。
- [ ] 摘要每个数值都能回溯到结果文件。
- [ ] 模型假设、变量、单位、边界和参数来源已定义。
- [ ] 结论没有“效果良好”“意义重大”等无证据套话。
- [ ] 局限、失效条件和可推广范围具体可核查。

## 图表、公式与引用

- [ ] 图、表、公式连续编号，正文至少引用一次。
- [ ] 图表可黑白打印，单位、有效数字和正文一致。
- [ ] 公式为可编辑 OMML 或可编译 LaTeX，不是截图。
- [ ] 正文引用与参考文献双向对应，作者/年份/来源/DOI 已核验。

## AI 合规

- [ ] 参考文献之前有官方二选一 AI 工具使用声明。
- [ ] 声明与支撑材料中的 `AI工具使用详情.pdf` 一致。
- [ ] 详情文件包含工具版本、用途、提示过程、采纳/修改/核验情况。
- [ ] 参赛队人工复核了全部 AI 输出，核心建模与分析由参赛队主导。

## 复现与交付

- [ ] 附录列出支撑材料文件名，代码完整可运行。
- [ ] 代码、数据、图表和论文使用同一份结果源。
- [ ] Word/DOCX、LaTeX、PDF 工具门禁和实际渲染抽检均通过。
- [ ] 任何校验警告都有官方条款或用户要求的明确解释。
