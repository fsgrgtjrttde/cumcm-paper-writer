# 获奖/展示论文风格画像

本文件把已审阅的公开 CUMCM 展示样本转化为可执行的写作规则。样本来源、覆盖范围和奖项证据见 `sample-corpus.md` 与 `sample-index.tsv`：当前可逐页核验的 62 篇是官方合作平台展示样本，页面并未统一标注国奖等级。因此可以学习其成熟论文的论证风格，不得把每篇都称为全国一等奖或用其内容替代当届规则。

## 使用顺序

1. 先按赛题把每个子问题标为机理、优化、评价、预测或数据挖掘中的一种或组合。
2. 为每个子问题填写“任务对象、输入/约束、模型、真实输出、验证、适用边界”。其中任何一项为空，先补证据，不写该节。
3. 从下表选择章节功能和语言动作，再按用户题目的变量、单位和真实结果成文。
4. 写后抽检：每一段能否指出一个模型对象、一个证据来源或一个限制条件；不能指出时删改，不用套话补足。

## 全文结构

成熟样本的共同点不是章节名完全一致，而是结论沿同一证据链推进：

```text
题目目标 -> 问题拆解 -> 假设/符号 -> 模型与求解
        -> 真实结果 -> 对照或验证 -> 有边界的结论
```

推荐正文结构为：问题重述与分析、假设与符号、数据/预处理、问题一至问题 n 的模型与结果、模型评价、AI 工具使用声明、参考文献、附录。每个问题节内部采用“分析—建模—求解—结果—验证—小结”，不因追求篇幅省略结果或验证。

## 摘要语言与结构

摘要优先承载结论可追溯性，按以下四种功能组织，通常不另设小标题：

| 功能 | 必须回答 | 推荐语言动作 | 禁止内容 |
|---|---|---|---|
| 任务界定 | 对象、数据/约束、总目标 | “针对……，需在……约束下完成……” | 大段赛题背景或价值宣言 |
| 问题级求解 | 每题的模型和输出 | “针对问题一，先……，建立……；采用……得到……” | 只列算法名 |
| 可信度 | 对照、误差、留出或灵敏度 | “通过……验证，……误差/指标为……” | “模型合理有效”而无指标 |
| 收束 | 适用场景与关键词 | “该方法可为……提供……” | 无边界的推广承诺 |

使用“本文”“针对问题一”“进一步”“由此”“结果表明”等客观连接语，但只在前后存在真实因果、推导或对比关系时使用。一个子问题至少写出“对象/约束 + 方法 + 输出 + 验证”中的前三项；存在验证时必须给出方法或指标。

## 正文段落动作

| 章节功能 | 段落应完成的动作 | 可用表达骨架 | 证据落点 |
|---|---|---|---|
| 问题分析 | 把自然语言要求转为输入、输出和难点 | “由……可知，关键在于确定……” | 题目附件、数据字典 |
| 假设 | 交代简化条件及影响 | “为使……可计算，假设……；该假设在……条件下可能失效。” | 领域资料、误差分析 |
| 建模 | 定义变量、目标、约束和参数来源 | “令……表示……，则目标函数为……” | 公式、符号表 |
| 求解 | 说明算法为何匹配问题及关键设置 | “考虑到……，采用……；停止准则/参数设为……” | 代码、配置、随机种子 |
| 结果 | 先报对象和口径，再报数值或趋势 | “在……情形下，方案……为……，相较于……变化……” | 表、图、结果文件 |
| 验证 | 说明比较对象、指标和结论 | “以……为基准，按……计算，误差为……” | 留出集、对照、敏感性试验 |
| 小结 | 仅收束已证明的结果和边界 | “因此，在……范围内，该方案能够……” | 本节模型与验证 |

“显著”“最优”“稳健”“有效”“创新”等判断是证据词，不是修辞词：分别需要统计检验/置信口径、可行域与目标值、扰动或极端场景、对照指标、以及可复现的机制或约束变化。

## 题型路由

| 题型 | 摘要和正文优先保留 | 典型验证 |
|---|---|---|
| 机理/仿真 | 控制方程、边界条件、参数单位、数值解 | 解析解、独立数值法、残差或实验数据 |
| 优化/规划 | 决策变量、目标、约束、方案值和可行性 | 基准方案、下界/上界、扰动与消融 |
| 评价/排序 | 指标体系、权重来源、评分口径、排序结果 | 一致性、权重敏感性、替代权重 |
| 预测 | 时间切分、特征、预测区间、误差定义 | 留出集、滚动验证、基线对比 |
| 数据挖掘/分类 | 清洗规则、特征、分类/聚类指标 | 交叉验证、混淆矩阵、外部验证 |

## 相似性与质量门禁

- 学习“论证功能和证据顺序”，不复用展示样本的标题、句子、公式推导、表格组织、数值或参考文献。
- 不制造“获奖腔”：删去“具有重要意义”“取得良好效果”“创新性强”等无法被结果或验证支持的评价。
- 不用过多“首先、其次、最后”替代逻辑；每个连接词都要能指出前后关系。
- 对摘要逐题核验模型、数值、单位和验证是否能回到正文、图表、代码输出或引用台账；不可回溯的信息不进入摘要。
- 在最终回复中说明样本范围和迁移层级，不能声称逐句模仿、已复制某篇获奖论文或因此可获得奖项。
